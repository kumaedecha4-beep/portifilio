## ✨ Key Features

- **🎨 Cultural Theme:** Designed with a vibrant Oromo-flag-inspired theme (Black, Red, and White) to represent my identity and pride.
- **❄️ Interactive UI:** Features a smooth, dynamic "Snow Effect" (Cabbi) using JavaScript for an immersive user experience.
- **📊 Global Interaction Bar:** A real-time interaction system where users can Like, Love, or Dislike projects, with a persistent View Counter (built with LocalStorage logic).
- **📱 Responsive Design:** Fully optimized for both Desktop and Mobile devices.
- **🏢 Professional Modal:** An interactive "About Me" section detailing my **3.7 GPA**, academic achievements at Bule Hora University, and work ethics.
- **⚙️ Tech Slider:** An infinite scrolling marquee showcasing my technical stack (Java, Python, Web Dev, etc.).
